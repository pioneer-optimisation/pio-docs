---
title: "Onboarding checklist"
description: "From project created to first optimised decision."
---

The dashboard tracks a new project through six stages: created, SDK installed, events arriving, inputs defined, model ready, and deployed. Each stage completes from observed facts, not self-report: the installed stage flips when your first events arrive, not when you say so.

The checklist is the front page of a new project and collapses once complete. Each incomplete stage links to the page where it gets done.
