## 1. Install

Install the SDK via UPM, pinned to an exact release tag. Full instructions land with the tested release.

## 2. Configure

Create your project in the dashboard and note the API key, account id, and project id.

## 3. Initialise

Register every action definition your game uses, each with a fallback, then initialise once at startup.

{/* snippet:init */}
```csharp Samples~/BasicIntegration/Assets/Scripts/QuickstartBootstrap.cs
var config = new PioConfig
{
    ApiKey = apiKey,
    AccountId = accountId,
    ProjectId = projectId,
    Actions = new Dictionary<string, ActionDef>
    {
        // Every action def carries a fallback: the action your game
        // uses when the backend cannot be reached in time.
        ["Tutorial"] = new ActionDef { FallbackAction = "Short" },
    },
};

await PIO.Init(config);
if (this == null) return; // Destroyed during the await: stop.
if (!PIO.IsReady)
{
    Debug.Log($"PIO init failed: {PIO.State}");
    return;
}
```
{/* /snippet:init */}

## 4. Request a decision

Ask for a decision at the decision point and apply the returned action. The fallback action comes back when the backend is unreachable, so your game never blocks on PIO.

{/* snippet:decision */}
```csharp Samples~/BasicIntegration/Assets/Scripts/QuickstartBootstrap.cs
// Offline, degraded, or timed out: the SDK serves the
// FallbackAction you registered. No null checks, no defaults.
var decision = await PIO.GetDecision("Tutorial");
if (this == null) return; // Destroyed during the await: stop.
var action = decision.Action;
```
{/* /snippet:decision */}

## 5. Track events

Valued events feed reward derivation; bare events record occurrences.

{/* snippet:event */}
```csharp Samples~/BasicIntegration/Assets/Scripts/QuickstartBootstrap.cs
// A valued event: the value feeds reward derivation.
PIO.TrackEvent("level_complete", 1.0);

// A bare occurrence, no value.
PIO.TrackEvent("tutorial_complete");
```
{/* /snippet:event */}

## 6. Verify

Run the game, then confirm events arrive: the `PIO/Verify Integration` editor menu and the dashboard's integration-health view.
