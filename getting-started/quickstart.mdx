The quickstart will walk through:

1. Install the SDK via UPM, pinned to an exact release tag
2. Configure `PioSettings`: API key, account, project
3. Initialise with `PIO.Init`
4. Request a decision with `PIO.GetDecision` and apply the returned action
5. Track a valued event with `PIO.TrackEvent`
6. Watch the events arrive in your dashboard

Every code block on this page is extracted from a sample project that compiles against each SDK release; the quickstart *cannot* drift from the SDK.
